# Privacidade e dados

O aplicativo desktop utiliza armazenamento local. A prévia 3.0 mantém dados separados do banco 2.x; o aplicativo Tauri usa o próprio banco. Sincronização e integrações externas são opcionais e devem ser avaliadas conforme a configuração utilizada. Consulte o README para os fluxos específicos do site e iCloud.

O SQLite da prévia e seus backups não são criptografados pelo novo módulo. Proteja o perfil do sistema e não envie arquivos reais a issues. A exclusão e retenção dependem dos arquivos locais e das cópias realizadas pelo usuário. Esta documentação não constitui garantia de ausência de tráfego de rede.
