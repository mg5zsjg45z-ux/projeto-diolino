# Lucide — subconjunto do Diolino

Origem: https://github.com/lucide-icons/lucide
Revisão fixada: 03f11e2d6adc319ea21e9a1d5820a99cd3767257
Consulta: 26/10/2026. Licenças ISC/MIT, reproduzidas integralmente em LICENSE.

Os SVG são preservados como fonte. PNGs transparentes de 144 × 144 são gerados
por scripts/render_visual_icons.cjs, com traço adaptado de 2 para 1,65 unidades.
A cor e o tamanho são aplicados localmente pelo Diolino. A distribuição não depende
de acesso à internet, da fonte de ícones do Windows nem do renderizador de compilação.
